# Legacy Rule Paths

This directory is kept for backward compatibility with existing Loon subscriptions.

Canonical rules now live in `../Lsr/` and use the `.lsr` extension.

- `Rule/Apple.list` → `Lsr/Apple.lsr`
- `Rule/Weverse.list` → `Lsr/Weverse.lsr`

Do not remove the legacy files unless all existing subscriptions have been migrated.
